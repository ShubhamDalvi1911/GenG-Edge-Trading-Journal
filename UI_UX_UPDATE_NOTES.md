# GenG Edge UI/UX Update

## Included
- Refined responsive dashboard filters for desktop, tablet, and mobile layouts.
- Improved mobile workspace navigation with horizontal scroll behavior.
- Polished dashboard surfaces, metric cards, inputs, focus states, and spacing.
- Refreshed Equity Curve presentation with a cleaner chart frame and premium tooltip.
- Equity Curve now sorts closed trades by actual exit time before calculating cumulative equity.
- Added starting-equity reference line and peak-equity guide line.
- Equity tooltip now exposes trade P&L, equity, peak equity, and drawdown.
- Improved chart density, axis readability, and mobile sizing.
- Added light-theme refinements for the updated dashboard controls and chart.
